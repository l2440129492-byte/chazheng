# 搜索授权与首次配置

Skill 使用当前宿主大模型判断证据，不调用额外的 LLM API。需要用户授权的是元宝搜索；已配置的元宝 MCP 无需重复索取 API Key。

## 本地输入页

运行 `python3 scripts/credentials.py setup`，程序会打开默认浏览器并打印一次性本机地址。用户亲自在密码框输入，勾选同意保存。成功后服务退出；页面可关闭。未输入则 30 分钟后关闭，不覆盖已有配置。修改密钥可重新运行同一命令。

页面不把密钥发给模型；浏览器经本机 HTTP 发送给 Python 程序，程序以后经 HTTPS 发送给元宝接口。地址只监听回环网络，随机端口和随机令牌、Host/Origin 校验用于限制其他网站提交。密码框只是避免屏幕直接显示内容，并非加密存储；不防同用户恶意程序、浏览器扩展或已被控制的电脑。不要录制输入过程。

Mac/Linux 的文件位于 `~/.config/yuanbao-detective/credentials.json`，目录 700、文件 600。写入采用临时文件替换。读取发现文件对其他用户开放或为符号链接时会拒绝，需由用户检查并修正权限。Windows 目前拒绝本地文件保存，避免把 POSIX 权限误说成 Windows 安全保障；使用平台密钥管理或元宝 MCP。

## 远程/云端宿主

本机是指运行 Python 的机器。云容器或 SSH 主机的 127.0.0.1 不等于用户电脑。不要把服务改成 0.0.0.0 或部署公网收密钥；改用平台专用秘密管理/MCP。只有已建立本地端口转发时，才可由用户通过对应本地地址访问。`--no-browser` 仅禁止自动开浏览器，不解决远程网络问题。

没有浏览器但有用户自己的交互终端时，可让用户运行 `python3 scripts/credentials.py terminal`，使用不回显输入并确认本地保存。不要在代理工具的普通标准输入中代填密钥；无交互终端会拒绝。

## 状态与删除

`python3 scripts/credentials.py status` 只显示配置状态与来源，不验证服务额度、权限或密钥有效性。`forget` 删除本地存储副本，不会撤销腾讯云密钥，也不会清理已有环境变量、旧 .env 或 MCP 授权；这些需在各自原处管理。首次查询真实鉴权失败时提示重新配置，失败响应不能回显密钥。
