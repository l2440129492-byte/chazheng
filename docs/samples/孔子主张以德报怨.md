# 查证报告：孔子主张以德报怨

- 时间：2026/10/24 18:03:33
- 作品：论语
- 要核实：核实“孔子主张以德报怨”是否为误传：孔子在《论语·宪问》中实际主张“以直报怨，以德报德”，“以德报怨”是他人（或曰）提出的说法。

## 结论：说法有偷换
孔子并不主张以德报怨。《论语·宪问》原文是别人问“以德报怨，何如”，孔子反问“何以报德”，并主张“以直报怨，以德报德”[2][3][11]。把提问当成孔子主张，属误传。

> “以德报怨”是否源于《老子》仅有百科提及[6]，未据原典核实。
